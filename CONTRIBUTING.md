Thank you for your interest in contributing to this theoretical framework. This is an open intellectual project—we welcome challenges, extensions, formalizations, and critiques.

## Ways to Contribute

### 0. Fastest ways to help

- **Report a flaw or a wrong citation**: [open an Issue](https://github.com/JBG-32/substratum-theory/issues/new).
- **Argue or propose**: [suggest an improvement](https://github.com/JBG-32/substratum-theory/issues/new?template=suggestion.yml), or [ask a question](https://github.com/JBG-32/substratum-theory/issues/new?template=question.yml).
- **Replies**: an AI assistant replies first on Juan Hinojosa's behalf and identifies itself as an AI. It never merges changes or edits the theory; anything needing Juan's answer is labelled `needs-juan` and passed to him.
- **Pick an open problem**: see Part XI of [THEORY.md](THEORY.md#part-xi-known-limitations-and-open-problems).

## Contribution Process

### For Small Changes

1. Open an Issue describing your proposed change
2. Fork the repository
3. Make your changes in a new branch
4. Submit a Pull Request referencing the Issue

### For Major Additions

1. Open an Issue for discussion first
2. Wait for community feedback
3. If consensus supports the direction, proceed with PR
4. Major additions should include their own documentation

### For Critiques

1. Open an Issue labeled `critique`
2. Be specific about which claims you're challenging
3. Provide reasoning or evidence
4. Propose alternatives if possible

## Standards

### Writing

- Clear, accessible language (avoid jargon where possible)
- Define technical terms when first used
- Acknowledge uncertainty appropriately
- Distinguish speculation from derivation

### Mathematics — the v3.0 rule

**No equation is displayed unless it is either (a) a standard, published result with a real citation, or (b) a proposed equation in which every symbol is defined, the index structure balances, units are consistent, and the equation reduces to known physics in a stated limit.** Anything else goes in words, tagged OUR HYPOTHESIS or SPECULATIVE.

- Show your work
- Define all variables, with units
- State assumptions explicitly
- Give the limit in which your equation reduces to established physics
- Add a check to `tools/equation_checks.py` for any new displayed equation and make sure the script still passes

### Claim tags

Every substantive claim must carry one of **ESTABLISHED** (cited), **OUR HYPOTHESIS**, or **SPECULATIVE**. PRs that present speculation as established will be asked to retag.

### Citations

Only real, verifiable citations (author, year, journal or arXiv id). If you cannot verify a reference, leave it out.

### Tone

- Good faith engagement
- Intellectual humility
- Constructive criticism
- Respect for all contributors
